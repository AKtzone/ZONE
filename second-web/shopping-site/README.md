# 购物网站子项目

## 项目概述
这是一个完整的前端购物网站子项目，包含所有核心电商功能模块，采用响应式设计，支持缅文、中文和英文三种语言。

## 功能特性

### 1. 商品展示区
- ✅ 网格/列表两种展示模式切换
- ✅ 商品图片、名称、价格、评分、库存状态完整显示
- ✅ 商品详情查看功能（模态框）
- ✅ 商品图片缩放效果

### 2. 商品分类导航
- ✅ 层级化分类菜单（6 个主分类，15 个子分类）
- ✅ 支持多级分类展开/收起
- ✅ 分类图标、名称及商品数量统计
- ✅ 移动端响应式折叠设计

### 3. 购物车功能
- ✅ 商品添加/删除/数量修改
- ✅ 价格实时计算
- ✅ 选中状态管理
- ✅ 购物车数据本地存储（localStorage）
- ✅ 与用户账户的同步

### 4. 用户账户管理
- ✅ 登录/注册入口
- ✅ 个人信息查看
- ✅ 订单历史查询入口
- ✅ 收货地址管理入口
- ✅ 用户状态本地持久化

### 5. 商品搜索功能
- ✅ 关键词搜索
- ✅ 搜索历史记录（最多 5 条）
- ✅ 搜索结果筛选
- ✅ 多种排序方式（价格、评分、销量）

### 6. 结算流程
- ✅ 四步骤结算界面
  - 步骤 1：购物车确认
  - 步骤 2：收货地址选择
  - 步骤 3：支付方式选择（信用卡、微信支付、支付宝、货到付款）
  - 步骤 4：订单预览及提交
- ✅ 订单摘要显示
- ✅ 运费计算逻辑

## 使用方法

### 方式 1：直接打开
直接在浏览器中打开 `shopping-site.html` 文件即可。

### 方式 2：使用本地服务器
```bash
# 使用 Python
cd shopping-site
python -m http.server 8080

# 使用 Node.js
npx http-server shopping-site -p 8080
```

然后在浏览器中访问 `http://localhost:8080/shopping-site.html`

### 方式 3：从主项目访问
1. 打开主项目 `index.html`
2. 点击"购物网站"项目卡片
3. 自动跳转到购物网站子项目

## 多语言支持

项目支持三种语言切换：
- 缅文（Myanmar）
- 中文（Chinese）
- 英文（English）

语言切换通过 `translations.js` 文件管理，所有翻译文本都已配置完成。

## 数据持久化

以下数据会保存到 localStorage：
- `shoppingCart`：购物车数据
- `currentUser`：当前用户信息
- `searchHistory`：搜索历史
- `preferredLanguage`：语言偏好

## 注意事项

1. **本地存储限制**：由于使用 localStorage，数据仅在当前浏览器有效
2. **模拟数据**：所有商品数据都是模拟数据，仅用于演示
3. **无后端**：当前版本无需后端服务器，纯前端实现
4. **图片加载**：商品图片来自 Unsplash，需要网络连接
