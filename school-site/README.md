# 教育学习平台 - Education Learning Platform

这是一个教育学习平台子项目，提供在线学习课程和教育资源。

## 功能特性

### 课程体系
- 前端开发入门课程
- Python编程基础课程
- 数据分析实战课程
- UI/UX设计全案课程

### 教学资源中心
- 教学视频
- 电子教材
- 习题库
- 参考文献

### 学习路径规划
- 入门阶段
- 进阶阶段
- 高级阶段

### 教育解决方案
- K12教育
- 职业教育
- 企业培训

### 学习评估系统
- 在线测验
- 自动评分
- 成绩分析
- 学习报告

### 师生互动社区
- 讨论区
- 问答板块
- 学习小组

## 技术栈

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

## 多语言支持

- 缅甸语 (MY)
- 中文 (CN)
- 英语 (EN)

## 运行方式

直接在浏览器中打开 `school-site.html` 即可运行。
